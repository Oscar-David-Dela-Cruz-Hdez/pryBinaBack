# Código Fuente del Sistema Web (Aplicación Web)

El código fuente del sistema web e-commerce se encuentra organizado en los siguientes repositorios:

* **Backend (Node.js / Express / MongoDB)**:
  `pryBinaBack/` (Directorio raíz del proyecto)
  Repositorio: https://github.com/Oscar-David-Dela-Cruz-Hdez/pryBinaBack

* **Frontend (Angular 17+ SPA)**:
  `pryBinaFront/`
  Repositorio: https://github.com/Oscar-David-Dela-Cruz-Hdez/pryBinaFront

### Requisitos de Ejecución
* Node.js v24.0+
* MongoDB 8.0+
* Angular CLI v17.0+
